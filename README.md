# guiton4848s040-Home-assistant-
Home Assistant Panel using Guiton 4848s040 esphome panel

Heavily based on https://github.com/alaltitov/Guition-ESP32-S3-4848S040 with fonts and pictures used directly from the Git
Use of Claude.ai to code.
Senors and light specific to my Home Assistant setup 
Relays on the device (i have the 3 relay one) are declared but not used in this instance

Bluetooth proxy is enabled on the device

2 different panel Yaml are now included
The second yaml, kitchenpanel has updated screen, removed the light widget and climate widget and just used the relays on the screen to control the outputs with different MDI icons based on the area light 
A number of pictures have been added showing the different panel screens IRL
